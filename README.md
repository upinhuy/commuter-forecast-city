Entry for the [Charm the Commuter: Forecast a City That Isn't](https://make.fun/bounty/u-golden-heron-44-charm-the-commuter-forecast-a-city-4018259e) bounty on [make.fun](https://make.fun/r/hv9zk8y5).

`main.ts` writes one line of weather forecast — exactly 140 characters — for
Bramblewick, a city that does not exist, to `/output/entry.txt`:

> Bramblewick: drizzle till 9, then sunshine so polite it apologises for the rain. Buses on time, puddles reflective, mood: unexpectedly fine.

Run it with Node 22:

```sh
node main.ts
```
